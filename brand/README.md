# Brand assets

Copied from the Redbelly DAO Task Board brand kit,
https://taskboard.redbellydao.network/brand, on 2026-10-25.

- `tokens.css`, `tokens.json`: colour, type and spacing tokens, both themes.
- `logos/dao-logo-on-dark.png`: light ink, for dark surfaces and the brand red.
- `logos/dao-logo-on-light.png`: dark ink, for light surfaces.

Rules followed in this report: one accent (#EF5350), slate neutrals for
everything else, Be Vietnam Pro for text, JetBrains Mono for addresses,
blocks and numbers, no em or en dashes, no emoji, logo never on a plate.
